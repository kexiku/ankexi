*Ankitty* is a minimalist Anki template that I use for my English vocabulary flashcards.
I maintain it primarily for the personal usage, but keep it public in case anyone would find it cool enough to add it to their study arsenal.

As the original creator states:
> *...it's designed mostly with language learning in mind, but at a glance there shouldn't be much in the way of using it for other subjects*

:star: Core features
- I spent multiple hours figuring out how to center cards in Anki, so you don't
  have to! (The magic is in finding the `.card > div` selector)
- All colors are variables, so swapping color schemes is easy
- Behaves consistently in both dark and light mode
- Looks fine on mobile
- Your study buddies will be jealous

## :hammer_and_wrench: Installation

You have 2 options:

### Ready-made deck

Example card pack to demonstrate all the features.
Just [download](https://github.com/satanori/Ankitty/raw/refs/heads/main/examples/Ankite-Example.apkg) and import to your collection.

### Template files

Layout templates you can manually add to your cards and customize as you wish.
Can be found [here](/templates)

<details>
  <summary>HTML & CSS</summary><br/>

  Open 'Manage Note Types' (`Ctrl` + `Shift` + `N`), then 'Cards', and copy-paste the code from each template file to the corresponding field
</details>

<details>
  <summary>Fields</summary><br/>

'Manage Note Types', 'Fields', then add fields to make the fields list look like this:

  <p>
    <img
      src="/assets/fields.png"

</details>


<details>
  <summary>Fonts</summary><br/>

  Follow the [Anki Manual on Installing Fonts](https://docs.ankiweb.net/templates/styling.html#installing-fonts)
</details>
